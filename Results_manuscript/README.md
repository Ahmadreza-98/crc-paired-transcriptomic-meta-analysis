# Results

`analysis.R` writes generated outputs to this directory.

```text
Results_manuscript/
├── Figures/
│   ├── Manuscript/
│   └── Supplementary/
├── Tables/
└── sessionInfo.txt
```

The complete output archive from the manuscript run is distributed separately on the repository's **GitHub Releases** page. It is provided for inspection and comparison; it is not required to run the analysis.
